# Contributing

## Development loop

```
npm ci
npm run dev        # Vite dev server
npm test           # Vitest, runs tests/**/*.test.ts against tests/fixtures/synthetic
npm run lint       # ESLint (type-aware) and Prettier check
npm run typecheck  # tsc --noEmit
npm run fixture    # regenerate tests/fixtures/synthetic (deterministic; commit the result)
```

Node 22.18 or newer is required: the CLI and tests import `.ts` files directly through Node's built-in type stripping, so the codebase avoids syntax that needs transpilation (`enum`, parameter properties, namespaces; enforced by `erasableSyntaxOnly` in tsconfig.json).

## Where code goes

- `src/core/`: pure functions over typed arrays. No DOM, no file system, no `fetch`. Every exported function is unit-tested against the synthetic fixture or a hand-built case.
- `src/io/`: parsers and the dataset boundary. Validation happens here and nowhere else; downstream code trusts `Dataset`.
- `src/workers/`: message plumbing only; calls into `src/core` and `src/io`.
- `src/ui/`: React screens and the canvas renderer. Screens do not compute; they display worker results.
- `src/export/`: serializers for CSV and the HTML report.

Each module starts with a header comment stating its responsibility and interface. Keep that current when the interface changes.

## Conventions

- Commits follow [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/): `feat(core): ...`, `fix(io): ...`, `docs: ...`, `test: ...`, `ci: ...`, `chore: ...`.
- Versions follow SemVer; user-visible changes go under `[Unreleased]` in CHANGELOG.md in the same pull request.
- Non-obvious decisions get a MADR record in `docs/adr/` (next free number, status `proposed` until merged).
- Output file contracts in `docs/data-formats.md` are versioned; changing a column is a `feat!` and a CHANGELOG entry under Changed.

## Test data

Never commit real genotype data. The fixture under `tests/fixtures/synthetic/` is generated by `scripts/make-fixture.mjs`; edit the generator, not the files, and keep the directory under 200 KB.
